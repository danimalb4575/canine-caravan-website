# Canine Caravan Coming Soon Site

This folder is ready to publish as a simple static website.

## Included files

- `index.html` — the website
- `style.css` — responsive desktop/mobile styling
- `canine-caravan-logo-white.png` — white transparent logo
- `favicon.png` — browser tab icon
- `CNAME` — tells GitHub Pages to use `caninecaravancompany.com`

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload every file in this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. In **Custom domain**, enter `caninecaravancompany.com`.

Do not change your Google Workspace MX, SPF, or DKIM records when connecting the website domain.
The website DNS records can be configured separately.
